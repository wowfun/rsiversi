# 完成第一次对话

[English](../../../user/first-conversation.md)

RSIversi 是在本机运行的 AI 工作空间，提供浏览器界面，也可以在终端中使用。
你需要自己的模型服务商账号和 API 密钥；服务商可能会按请求收费。
RSIversi 仍处于预发布阶段，不同版本的保存格式可能发生变化。

## 安装并打开

按照[从源码安装](source-install.md)完成准备，然后在仓库目录执行 Web 启动命令。
使用期间保持这个终端窗口打开。浏览器会自动打开一次性登录链接。
如果没有自动打开，复制终端中打印的完整链接。这个链接相当于密码，不要分享。

打开后应能看到对话工作空间。首次启动时没有模型是正常情况，
你不需要编辑 Profile 或 JSON 文件。

## 连接模型

打开 **Settings → Models & access（设置 → 模型与访问权限）**。
[配置模型](model-setup.md)会带你分别保存凭据、服务商和默认模型。
只保存 API 密钥不会完成模型配置。

## 发送第一条消息

选择 **New conversation（新对话）**，并指定本地工作目录。
Windows 暂不支持目录浏览器，请手工输入绝对路径，例如 `D:\Projects\my-project`，
并使用固定本地 NTFS 磁盘上的目录。

先发送一条纯文本消息，例如“请介绍你能如何帮助我审阅项目”，然后等待回复完成。
对话会出现在历史记录中，重新打开后可以看到已保存的消息。

Windows 当前支持对话和原生文件访问，受限 Shell 命令暂不可用。
命令被拒绝不等于模型连接失败，详见[平台限制与故障排查](troubleshooting.md)。

## 退出并回来

关闭浏览器标签页后，服务仍在运行。要停止 RSIversi，请在启动它的终端按 Ctrl+C，
并等待进程退出。下次启动 Web 后，可以从历史记录中打开之前的对话。
Windows 上请先停止 Web，再启动[终端界面](terminal.md)或使用离线设备管理。

成功收到第一次回复后，可以继续阅读[日常使用](daily-use.md)。
