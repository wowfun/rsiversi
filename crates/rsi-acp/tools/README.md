# rsi-acp-tools

`external_agent` is an ordinary Agent contribution over the same Host capability
used by direct clients. It lists configured endpoint IDs, starts a conversation,
submits one follow-up, reads observed history, cancels or closes it. It accepts no
command, environment, path or permission answer. Humans answer the exact peer
options through the product's external conversation controller.

A start identity derives from the live native caller and exact Tool call identity.
Repeating that start reconciles its saved observation; start never sends a prompt.
Follow-up is a separate one-shot operation and an unknown result must not be resent.
Other operations are narrowed to identities in that native caller's delegation
namespace. Host-owned peers outlive the Tool invocation and UI detach. Reading a
result reports local observed status and source records, not remote durability or
objective success. Tool outputs retain a frozen structured output declaration.
