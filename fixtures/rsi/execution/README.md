# Execution authority fixtures

These deterministic providers exercise the public Execution resolver, admission,
lease and process seams. Metadata fixtures model location visibility and grant
revocation without opening an SSH connection; process fixtures observe target
selection without invoking a live service. They provide controller and authority
evidence, not native SSH or operating-system enforcement evidence.

Agent Kernel/executor/composition, Bash, Files Tools and standard-product Session,
history, Session Files and Workspace Review tests include these modules by path.
Run the consuming crate's affected test target; this directory has no standalone
Cargo workspace or lockfile.
