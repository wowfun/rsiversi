# History product acceptance

`browser.mjs REPORT` drives actual authenticated Chromium and Firefox clients
against an isolated standard Host, SQLite cache and deterministic HTTP provider.
It indexes a native source, opens the verified original, selects a Unicode
fragment, freezes it for an unpublished target and preserves the existing draft.
The browser selects conversation scope, continues discovery and inspects source
coverage before checking a miss and a hit. Opening the picker already starts
discovery, so the fixture never assumes the initial index is empty.
Screenshots cover matches, selected original, frozen review and narrow rendering.
Prepare the [shared paired-publication supervisor](../web-product/README.md).
Build the paired publication first with `pnpm -C apps/web build ABSOLUTE_PACKAGE_DIRECTORY --debug`.
The fixture resolves its binary and assets using the `target/rsi-app/web/current` generation record;
`RSI_PAIRED_BUNDLE` selects another complete paired publication. This
fixture does not install source copies, use credentials or claim native desktop
or live-provider coverage.
