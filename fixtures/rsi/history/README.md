# History product acceptance

`browser.mjs REPORT` drives actual authenticated Chromium and Firefox clients
against an isolated standard Host, SQLite cache and deterministic HTTP provider.
It indexes a native source, opens the verified original, selects a Unicode
fragment, freezes it for an unpublished target and preserves the existing draft.
Screenshots cover matches, selected original, frozen review and narrow rendering.
Set `RSI_BINARY` and absolute `RSI_WEB_ASSETS` to already built artifacts. This
fixture does not install source copies, use credentials or claim native desktop
or live-provider coverage.
