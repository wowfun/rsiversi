## Problem

A preset declaration, an active registration and a tool offered in a particular model request can differ. Operators also need to distinguish an executor waiting to retry from an interrupted model call. Users with long sessions currently have to wait for context pressure before requesting a summary.

## Decision

The local profile compiler attributes declarations, patches and enablement during inspection. The source trace has no role in generation identity. The historical request reader compares captured definitions with the preceding request of the same purpose. Active runtime observations remain scoped to their generation.

An idle command reserves the Kernel admission key and commits its own summary effect before provider dispatch. Paid retry decisions belong to the failed attempt. The following physical start carries the reserved effect ID. Both features use Session 40 and Store 52. An incompatible pre-release store stays intact for explicit operator recovery.

Parallel-safe tool calls use a default limit of ten per batch. A free slot admits the next source position when pending outcomes have capacity. A complete wave of intents and starts becomes durable before its bodies execute. The [tool overlap decision](../architecture/2026-09-03-owner-declared-tool-overlap.md) owns scheduling declarations and exclusive barriers.

## Alternatives considered

Re-evaluating predicates on the current generation cannot establish an old request's tools. Queueing a busy compaction across restart could initiate an unexpected paid call. A global concurrency permit would couple unrelated sessions and parked child waits. Dedicated filesystem search remains deferred until its local and remote authority can be specified.

## Consequences

A slow head or a pending approval can delay new starts. Already admitted bodies continue and successful outcomes publish in source order. Small waves can add durability flushes. A scheduled retry can survive cancellation without a matching provider start. A disconnected compact command can leave only its recorded start. Reopening observes that evidence without initiating another paid request.
